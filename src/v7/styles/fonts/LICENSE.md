# The typefaces in this folder

Each file is the Latin subset of a variable font, as Google Fonts serves it, kept here so that the site asks no font host
at run time (`../fonts.css`).

| File | Typeface | Copyright | Licence |
|---|---|---|---|
| `fraunces-latin.woff2` | Fraunces | Copyright 2020 The Fraunces Project Authors (https://github.com/undercasetype/Fraunces) | SIL Open Font License 1.1 |
| `nunito-latin.woff2` | Nunito | Copyright 2014 The Nunito Project Authors (https://github.com/googlefonts/nunito) | SIL Open Font License 1.1 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) | SIL Open Font License 1.1 |

The SIL Open Font License 1.1 is at https://openfontlicense.org/open-font-license-official-text/. It lets the fonts be
used, embedded in a web site and redistributed with it, so long as they are not sold on their own and their reserved
names are not used for a changed version. These files are unchanged.
